**Dashboard Xbox Game Pass**

Desenvolvi este projeto utilizando exclusivamente o Microsoft Excel, com o objetivo de transformar uma base de dados de assinaturas do Xbox Game Pass em um dashboard interativo, visual e orientado à análise de resultados.

A estrutura do projeto foi organizada em diferentes abas, mantendo a base de dados original em uma planilha oculta chamada “Bases”, contendo informações como ID do assinante, nome, plano contratado, data de início, renovação automática, preço da assinatura, periodicidade, contratação de EA Play Season Pass, Minecraft Season Pass, valores adicionais, cupons e valor total da assinatura.

A partir dessa base, utilizei recursos nativos do Excel para realizar o tratamento, organização e consolidação das informações, criando uma camada de cálculos e análises em uma segunda aba oculta. Nessa etapa foram desenvolvidas tabelas dinâmicas e cálculos destinados a responder perguntas de negócio, como:

faturamento relacionado aos planos;
comparação entre assinaturas com e sem renovação automática;
faturamento de assinaturas adicionais do EA Play Season Pass;
faturamento do Minecraft Season Pass;
análise dos valores totais das assinaturas.

O dashboard foi construído utilizando elementos visuais do próprio Excel, incluindo cartões de indicadores, gráficos, segmentações/filtros, formas, imagens, identidade visual e elementos de navegação, permitindo transformar os dados brutos em uma apresentação mais intuitiva.

Também utilizei uma paleta visual inspirada na identidade do Xbox, com predominância de tons verdes e elementos de contraste, além de recursos gráficos para destacar os principais indicadores. O painel apresenta, entre outros indicadores, os valores de assinaturas do EA Play Season Pass e assinaturas do Minecraft Season Pass, calculados a partir da base utilizada no projeto.

Um dos pontos importantes da construção foi a separação entre base de dados, cálculos e apresentação, mantendo as abas de suporte ocultas para deixar a experiência final mais limpa e concentrada no dashboard. Dessa forma, o arquivo funciona não apenas como uma apresentação visual, mas como uma estrutura completa de análise de dados dentro do Excel, na qual os indicadores e gráficos são alimentados pelas informações existentes na base.

Todo o desenvolvimento foi realizado sem utilização de Power BI, Python, SQL ou outras ferramentas externas, utilizando exclusivamente os recursos disponibilizados pelo Microsoft Excel, como tabelas, tabelas dinâmicas, fórmulas, gráficos, segmentações, formatação, elementos visuais e organização estruturada das informações.
